# maps — карты мира

Официальные карты GTA V в разрешении около 1920 px: Сан-Андреас (дорожная,
спутниковая, атласная, чёрно-белая), карты улиц Лос-Сантоса и Блэйн-Каунти,
постерная карта, а также отдельные карты Северного Янктона и Кайо-Перико.
Источник: GTA V official map (Rockstar, via gtabase.com).

**labeled** — с крупными читаемыми подписями регионов, **plain** — без них
(только мелкие «родные» надписи или вообще ничего).

## Сан-Андреас целиком

| Файл | Описание |
|---|---|
| `gta_5_map_roadmap_hd_1920.jpg` | Дорожная карта, **plain** — самая чистая основа под оверлей: маршруты, метки, свои подписи. |
| `gta_5_map_roadmap_labels_1920.jpg` | Та же дорожная карта, **labeled** — основная «объясняющая» карта, названия читаются даже на телефоне. |
| `gta_5_map_satellite_hd_1920.jpg` | Спутник, **plain** — самая детальная карта папки, лучшая под глубокие зумы до квартала. |
| `gta_5_map_satellite_labels_1920.jpg` | Спутник, **labeled** — компромисс фактуры и читаемости для обзорных планов. |
| `gta_5_map_atlas_hd_1920.jpg` | Атласный (туристический) стиль, **plain** — тёплая декоративная подложка под заголовок. |
| `gta_5_map_black_white_in_game_1920.jpg` | Чёрно-белая внутриигровая карта, **plain** — под тёмные монтажи и HUD-стилизацию. |
| `gta_5_map_satellite_night_1920.jpg` | Ночной спутник, **plain** — огни Лос-Сантоса на чёрном острове, логотип GTA V в углу; самый эффектный кадр для титров. |
| `gta_5_map_official_poster_1920.jpg` | Постерная карта из комплекта игры, **labeled**: сетка A–I / 1–7, роза ветров, схема метро. **Вотермарка WWW.GTA-SERIES.COM по нижней трети.** |
