# GTA 5 Asset Library — правила для Claude

Это библиотека медиа-материалов (картинки, скриншоты, логотипы, арты) для создания видеорядов про GTA V и GTA Online. Claude сам модерирует репозиторий по этим правилам.

## Структура

```
characters/    персонажи (Michael, Franklin, Trevor, NPC) — подпапка на персонажа
locations/     локации (Los Santos, Blaine County, Vinewood...) — подпапка на локацию
vehicles/      транспорт
weapons/       оружие
logos/         логотипы (Rockstar, GTA V, внутриигровые бренды)
screenshots/   скриншоты из трейлеров/геймплея; подпапки: story_mode, online, trailers
artwork/       официальные арты, постеры, ключевые арты, обложки
maps/          карты и фрагменты карты
ui/            интерфейс, шрифты, HUD
misc/          всё, что не подошло выше
```

Подпапки создавай по мере накопления: если в папке 3+ файла про одну сущность — выноси в подпапку (`characters/trevor_philips/`).

## Правила для каждого ассета

1. **Имя файла** — человекочитаемое, snake_case, на английском: `trevor_trailer2_desert_01.jpg`, не `IMG_2041.png`.
2. **Sidecar-описание** — рядом с каждым файлом `имя.md` с фронтматтером:

```markdown
---
title: Trevor in the desert
source: GTA V Trailer 2 (Rockstar)
type: screenshot
tags: [trevor, desert, blaine-county, day]
resolution: 1920x1080
license: Rockstar promo / fair use
added: 2026-07-25
---

Тревор стоит посреди пустыни Блэйн-Каунти на закате. Подходит для сцен
про безумие Тревора и атмосферу глубинки.
```

3. **INDEX.md в корне каждой папки** — таблица: файл → одна строка описания. Обновляй при каждом добавлении/удалении.
4. **Корневой INDEX.md** — дерево всей библиотеки. Это первое, что читаешь при поиске ассета.

## Модерация (делай сам при каждой работе с репо)

- Новый файл без описания → создай sidecar `.md` (посмотри картинку через Read и опиши её).
- Файл с мусорным именем → переименуй по конвенции.
- Дубликаты → удали худший по качеству.
- Пережатые копии того, что уже есть в лучшем качестве, не добавляем.
- Фанатский контент — только с указанием автора (`license: Fan-made / community`).
- Видео >100 МБ в git не пушить (`*.mp4` в .gitignore) — кадры извлекать через ffmpeg.
- После изменений → обнови INDEX.md и закоммить с осмысленным сообщением (от ai2bteam, без Co-Authored-By).

## Поиск ассетов

При задаче «найди картинку X для видео»: сначала `INDEX.md` корня → INDEX нужной папки → фронтматтер-теги (`grep -r "tags:.*слово" --include="*.md"`).
