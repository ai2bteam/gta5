# Источники материалов по GTA V

Реестр проверенных сайтов для пополнения библиотеки. Обновляй при находке новых.

| Источник | Что даёт | Доступ | Заметки |
|---|---|---|---|
| gtabase.com/grand-theft-auto-v/ | галереи скриншотов и артов, базы: персонажи, машины, оружие, карта | **только браузер** — Cloudflare блокирует curl/WebFetch; скачивание: fetch внутри страницы → POST base64 на локальный HTTP-приёмник (порт 8931) | основной источник библиотеки |
| rockstargames.com/gta-v | официальный сайт: downloads (обои, аватары), артворки | React-приложение, возможен age gate | медиа на CDN akamaized.net |
| rockstarintel.com | новости | WebFetch работает | для новостных дайджестов |

## Правила отбора

1. **Не дублировать**: перед скачиванием проверь INDEX.md.
2. **Фанатский контент** — только с указанием автора в sidecar (`license: Fan-made / community`).
3. **Тексты сайтов не копировать** — факты пересказывать своими словами со ссылкой на источник.
4. **Официальный контент Rockstar** — `license: Rockstar promo / fair use`.
